[======= NEW FEATURES AND BUG FIXES =======]

+ Changed how variables are declared!
 - Variable Declaration:
   To declare a variable in SiHTML, use the @var command followed by the
   variable name and its initial value. For example:
   `@var | x = 4`  This line declares a variable x and initializes it with the value 4.

   Variable Reference:
   To reference a variable in SiHTML, use the var["variable_name"] syntax. For instance:
   `@var | y = 7 + var["x"]`  Here, y is assigned the value 7 plus the value of variable x.

   Data Type Casting:
   You can perform data type casting in SiHTML using standard function syntax. For example:
   `@var | z = int( (var["x"] + var["y"]) / 2)` In this case, the expression
   int( var["x"] + var["y"] ) converts the sum of variables x and y to an integer
   before dividing by 2 and assigning the result to variable z.

   !!! This uses the `eval()` command within Python. !!!
